# INFERNO — живые обои «Ад Данте» на три монитора

Три монитора складываются в один спуск по Аду:

| Монитор | Круги (сверху вниз) | Что там происходит |
|---|---|---|
| **1** | I Лимб · II Сладострастие · III Чревоугодие | души вздыхают у замка о семи стенах · любовники несутся в вихре (Паоло и Франческа вдвоём) · чревоугодники лежат под ледяным дождём, Цербер ходит среди них |
| **2** | IV Скупость · V Гнев · VI Ересь | скупцы и моты катят золотые валуны и сшибаются («Perché tieni? — Perché burli?») · драка в болоте Стикс, лодка Флегия · горящие гробницы у стен Дита, Фарината встаёт из гроба, фурии на стене |
| **3** | VII Насилие · VIII Злые Щели · IX Предательство | кровавый Флегетон и кентавры с луками, лес самоубийц с гарпиями, огненный дождь · 10 рвов под мостами, в каждом свои грешники · ледяной Коцит, Уголино, трёхликий Люцифер грызёт Иуду |

**Как это работает:** Данте (в красном) и Вергилий (в лавровом венке) идут по кругам
по очереди, примерно минуту по каждому. Круг, где они сейчас, подсвечен, в нём
появляется цитата из «Божественной комедии». Уходя с правого края одного монитора,
они появляются на следующем. Все три обоины берут время из системных часов, поэтому
идут синхронно. Через 9 минут на всех экранах загораются звёзды:
*«e quindi uscimmo a riveder le stelle»*. После этого спуск начинается заново.
В правом нижнем углу есть маленькая воронка, на ней видно, где сейчас поэты.

## Файлы

```
animated/dist/inferno-monitor-1.zip   ← живые обои для левого монитора
animated/dist/inferno-monitor-2.zip   ← для среднего
animated/dist/inferno-monitor-3.zip   ← для правого
animated/dist/inferno-span.zip        ← один холст на все 3 монитора (режим Span)
animated/dist/inferno-single.zip      ← для одного монитора: сам показывает круги, где сейчас поэты
stills/monitor-*.png                  ← статичные 4K-кадры для каждого монитора
bonus/sigil.png, bonus/abyss.png      ← ещё две статичные 4K-обои: неоновая «печать» кругов и вид со дна Ада на звёзды
```

Чтобы посмотреть в браузере, открой `animated/dist/inferno-span/index.html`.
Параметр `?t=480` в адресе перематывает к нужной секунде цикла (480 — это Люцифер).

## Windows: Lively Wallpaper (бесплатно, рекомендую)

1. Установи **Lively Wallpaper** из Microsoft Store или с GitHub (rocksdanister/lively).
2. Нажми **«+» (Add Wallpaper)** и перетащи `inferno-monitor-1.zip`, потом `-2.zip` и `-3.zip`.
3. В Lively открой **значок монитора вверху** (Choose display) или *Settings → Wallpaper → Display*,
   выбери режим **Per Display** (у каждого экрана свои обои).
4. Кликни монитор 1 и выбери «Inferno — Монитор 1». Так же с мониторами 2 и 3.
   Если мониторы стоят в другом порядке, просто назначь им другие файлы.
5. Через **⋯ → Customise** можно поменять длину спуска (5–15 минут), FPS, отключить подписи
   или переключить, какие круги показывать.

Вариант без раскладки: в Lively выбери режим **Span** и поставь `inferno-span.zip`.
Он растянет все 9 кругов на три экрана сразу.

Lively сам ставит обои на паузу, когда открыта игра или окно на весь экран.

## Windows: Wallpaper Engine (Steam, платно)

Открой Wallpaper Engine, выбери **Open Wallpaper → Open from File**, укажи `index.html`
из нужной папки (`inferno-monitor-1` и т.д.). Монитор выбирается вверху окна WE.
В настройках обоины есть пункт «Какие круги».

## Только статичные картинки

**Windows 10/11:** *Параметры → Персонализация → Фон → «Изображение»*. Нажми **правой кнопкой**
на картинку в списке недавних и выбери **«Установить для монитора 1/2/3»**.
Сначала добавь картинки через «Обзор фотографий».

**macOS:** *Системные настройки → Обои*. Если мониторов несколько, у каждого своя
миниатюра, выбери картинку для каждого.
