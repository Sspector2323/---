# INFERNO — живые обои «Ад Данте» на три монитора

Каждый монитор — готический триптих: каменная рама с тремя стрельчатыми окнами,
в каждом окне свой круг Ада. Три монитора вместе — весь спуск, все девять кругов.

| Монитор | Окна | Что происходит |
|---|---|---|
| **1** | I Лимб · II Сладострастие · III Чревоугодие | призрачные тени бродят у замка о семи стенах · души несутся в адском смерче, Паоло и Франческа вдвоём, бьют молнии · ливень и град над грешниками в грязи, трёхглавый Цербер с горящими глазами |
| **2** | IV Скупость · V Гнев · VI Ересь | скупцы и моты толкают золотые грузы и сшибаются («Perché tieni? — Perché burli?») · драка в болоте Стикс, лодка Флегия, сигнальные огни башни Дита · горящие гробницы, Фарината встаёт из гроба, фурии на стене |
| **3** | VII Насилие · VIII Злые Щели · IX Предательство | огненный дождь, лес самоубийц с гарпиями, кентавры стреляют в кипящую кровь · рвы с огненными языками, лицемерами в золотых плащах, ворами и змеями, бесы с крючьями · ледяной Коцит: головы во льду, Уголино, трёхликий Люцифер машет крыльями |

**Как это работает.** Данте (красный плащ) и Вергилий (лавровый венок) идут через окна
по порядку, около минуты на каждый круг. Окно, где они сейчас, обводится светом, табличка
под ним загорается, а в окне появляется строка из «Божественной комедии» с переводом.
Между окнами поэты проходят за каменными колоннами, с правого края монитора переходят
на следующий. Время берётся из системных часов, поэтому три монитора идут синхронно.
Через 9 минут во всех окнах загораются звёзды: *«e quindi uscimmo a riveder le stelle»*.
Потом спуск начинается заново.

## Файлы

```
v2/dist/inferno-monitor-1.zip   ← живые обои для левого монитора (I–III)
v2/dist/inferno-monitor-2.zip   ← для среднего (IV–VI)
v2/dist/inferno-monitor-3.zip   ← для правого (VII–IX)
v2/dist/inferno-span.zip        ← все 9 окон одним холстом на три монитора (режим Span)
v2/dist/inferno-single.zip      ← для одного монитора: показывает окна, где сейчас поэты
v2/dist/inferno-span/index.html ← можно открыть в браузере и посмотреть
stills/*.jpg                    ← статичные 4K-кадры, по одному на монитор
bonus/                          ← ещё две статичные 4K-обои (неоновая «печать» и вид со дна Ада)
```

Перемотать к нужному моменту: добавь к адресу в браузере `?t=480`, это секунда цикла
(480 — Люцифер, 530 — звёзды).

## Windows: Lively Wallpaper (бесплатно)

1. Установи **Lively Wallpaper** (Microsoft Store или github.com/rocksdanister/lively).
2. Нажми **«+»** и перетащи `inferno-monitor-1.zip`, `-2.zip`, `-3.zip`.
3. Нажми значок экрана вверху и выбери раскладку **Per Display**.
4. Выбери монитор 1 и поставь «Inferno — Монитор 1», потом так же мониторы 2 и 3.
5. **⋯ → Customise**: длина спуска (5–15 минут), FPS, цитаты, какие круги показывать.

Можно проще: раскладка **Span** и один файл `inferno-span.zip` на все три экрана.
Пока ты в игре или в полноэкранном окне, Lively ставит обои на паузу.

## Wallpaper Engine (Steam)

**Open Wallpaper → Open from File**, выбери `index.html` в распакованной папке нужного монитора.
Монитор назначается вверху окна Wallpaper Engine.

## Только картинки (Windows 10/11)

*Параметры → Персонализация → Фон → Изображение*: добавь картинки из `stills/`,
нажми **правой кнопкой** на картинку и выбери **«Установить для монитора 1/2/3»**.

## Как это сделано / пересобрать

* `v2/plates/plates.py` — девять фоновых картин (рельеф с освещением, перспектива, отражения, туман).
* `v2/plates/frame.py` — каменная рама с гравировкой.
* `v2/engine/inferno2.js` — анимация на Canvas: силуэты с контровым светом, огонь, дождь, пепел, туман, поэты.
* `cd v2/plates && python3 plates.py && python3 frame.py && cd .. && python3 build.py`
