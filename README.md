# Бот Витус — общение (без n8n)

Полный перенос n8n-воркфлоу **«Бот Витус Общение»** в код на Python (aiogram 3).
Работает на Railway, без подписки n8n. Исходный воркфлоу лежит в `n8n/bot_vitus_obshchenie.json`.

## Что делает бот (1-в-1 как в n8n)

| n8n-нода | В коде |
|---|---|
| Telegram Trigger + «Фильтр: только личка» | отвечает только в личке, группы игнорирует |
| «База игроков» (append в Google Sheets) | каждое сообщение пишется в таблицу: ID, Name, Username, Date, Точная дата, Language, text, Bot |
| If `/start` или `Привет` → «Розыгрыш» | фото «Новое колесо в FARO» с подписью |
| AI Agent + OpenAI gpt-4o-mini + Simple Memory | ИИ-ответ с тем же системным промптом, max 200 токенов, t=0.7, помнит последние 5 пар сообщений |
| Wait 10 сек → «Send a text message» | через 10 секунд после любого ответа — «⚠️ ВАЖНО!» с 4 кнопками-мини-приложениями |
| Все «Рассылка …» + «ЗАПУСК РАССЫЛКИ» | команда `/broadcasts` в боте (только для админов) |

Что добавлено сверху:

* **Рассылки из Telegram**, а не кнопкой в n8n: `/broadcasts` → выбираешь шаблон → бот показывает превью → «✅ Отправить». В конце приходит отчёт (доставлено / заблокировали / ошибки). Дубли ID убираются, как «ФИЛЬТР ОЧИСТКИ ОДИНАКОВЫХ ID».
* `/send` — ответь этой командой на любое своё сообщение (текст, фото, видео, пост) — бот разошлёт копию всей базе. Это и есть «авто-рассылка поста о стриме» из планов на стикере.
* `/stats` — сколько уникальных людей в базе, `/myid` — узнать свой Telegram ID, `/admin` — подсказка.
* Если ИИ прислал битый HTML — сообщение уйдёт без разметки, а не потеряется. Если картинка не грузится — пост уйдёт текстом.
* Флуд-лимиты Telegram обрабатываются автоматически.

Шаблоны рассылок: колесо, итоги розыгрыша, стрим начался, анонс клипа, стрим (серый), моменты со стрима, стрим → в канал `-1001407379425`.
Все тексты, картинки, кнопки и промпт — в `bot/texts.py`. Поменял и запушил → Railway сам передеплоит.

## Секреты (переменные окружения)

Секреты **не хранятся в репозитории** — они задаются в Railway → сервис → **Variables** (шаблон в `.env.example`).
Из экспорта n8n ключи достать нельзя (там только ID кредов), поэтому их нужно вставить один раз вручную.

| Переменная | Обязательно | Где взять |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | @BotFather → твой бот → API Token (тот же бот, что в n8n) |
| `OPENAI_API_KEY` | да | https://platform.openai.com/api-keys |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | да* | JSON-ключ сервисного аккаунта Google (см. ниже) |
| `ADMIN_IDS` | да | твой Telegram ID (напиши боту `/myid`), несколько — через запятую |
| `SPREADSHEET_ID` | нет | по умолчанию таблица «База игроков» `16GFYOAe74YSPDDMLGPxvKjFS0d6heVbvs7VgUs_-Tnw` |
| `SHEET_GID` | нет | `0` — лист «Основная база» |
| `OPENAI_MODEL`, `OPENAI_MAX_TOKENS`, `OPENAI_TEMPERATURE`, `MEMORY_WINDOW` | нет | `gpt-4o-mini`, `200`, `0.7`, `5` |
| `FOLLOWUP_DELAY` | нет | `10` — задержка перед «⚠️ ВАЖНО!» |
| `PROMO_CHANNEL_ID` | нет | `-1001407379425` |

\* без него бот отвечает, но не пишет в таблицу и не делает рассылки.

### Google-таблица (сервисный аккаунт, 5 минут)

1. https://console.cloud.google.com → создать проект (или взять любой).
2. **APIs & Services → Library** → включить **Google Sheets API**.
3. **IAM & Admin → Service Accounts → Create** → любое имя → **Keys → Add key → JSON** — скачается файл.
4. Открыть таблицу «База игроков» → **Поделиться** → вставить `client_email` из JSON (вида `...@...iam.gserviceaccount.com`) → роль **Редактор**.
5. Весь текст JSON-файла вставить в Railway в переменную `GOOGLE_SERVICE_ACCOUNT_JSON` (можно и в base64).

## Деплой на Railway

1. https://railway.com → **New Project → Deploy from GitHub repo** → выбрать этот репозиторий.
2. В сервисе → **Variables** → добавить переменные из таблицы выше (удобно через **Raw Editor**, вставив `.env.example` с заполненными значениями).
3. Railway сам поставит Python, зависимости из `requirements.txt` и запустит `python -m bot` (см. `railway.json`). Домен/порт не нужен — бот работает через long polling.
4. **Выключи воркфлоу в n8n** (Active → off). Иначе n8n снова поставит свой вебхук и будет перехватывать сообщения. Бот при старте сам снимает вебхук n8n.
5. В логах Railway должно появиться `Бот @... запущен`. Напиши боту `/start`.

Держи ровно **1 реплику** — два запущенных экземпляра с одним токеном конфликтуют.

## Локальный запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить
set -a; source .env; set +a
python -m bot
```

## Структура

```
bot/
  __main__.py   запуск, снятие вебхука, polling
  handlers.py   сценарий общения + админка рассылок
  ai.py         OpenAI + память диалога
  sheets.py     Google Sheets: запись сообщений, чтение базы
  broadcast.py  рассылки с отчётом
  sender.py     отправка с защитой от ошибок Telegram
  texts.py      все тексты, картинки, кнопки, промпт
  config.py     переменные окружения
```

Память диалога хранится в оперативке (как Simple Memory в n8n) и сбрасывается при перезапуске.
