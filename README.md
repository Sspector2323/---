# Бот Витус — общение (без n8n)

Полный перенос n8n-воркфлоу **«Бот Витус Общение»** в код на Python (aiogram 3).
Работает на Railway, без подписки n8n. Исходный воркфлоу лежит в `n8n/bot_vitus_obshchenie.json`.

## Что делает бот (1-в-1 как в n8n)

| n8n-нода | В коде |
|---|---|
| Telegram Trigger + «Фильтр: только личка» | отвечает только в личке, группы игнорирует |
| «База игроков» (append в Google Sheets) | каждое сообщение пишется в таблицу: ID, Name, Username, Date, Точная дата, Language, text, Bot |
| If `/start` или `Привет` → «Розыгрыш» | фото «Новое колесо в FARO» с подписью |
| AI Agent + OpenAI gpt-4o-mini + Simple Memory | ИИ-ответ с тем же системным промптом, max 200 токенов, t=0.7, помнит последние 5 пар сообщений |
| Wait 10 сек → «Send a text message» | через 10 секунд после любого ответа — «⚠️ ВАЖНО!» с 4 кнопками-мини-приложениями |
| Все «Рассылка …» + «ЗАПУСК РАССЫЛКИ» | команда `/broadcasts` в боте (только для админов) |

Что добавлено сверху:

* **Рассылки из Telegram**, а не кнопкой в n8n: `/broadcasts` → выбираешь шаблон → бот показывает превью → «✅ Отправить». В конце приходит отчёт (доставлено / заблокировали / ошибки). Дубли ID убираются, как «ФИЛЬТР ОЧИСТКИ ОДИНАКОВЫХ ID».
* **Админский режим.** Админам (`ADMIN_IDS`) ИИ не отвечает и «⚠️ ВАЖНО!» не шлёт, их сообщения не пишутся в базу. Любой пост (текст, фото, видео, альбом), присланный боту, — это черновик: бот спрашивает «👥 Всей базе / 📣 В канал / ❌ Отмена». `/usermode` временно включает режим обычного пользователя, чтобы проверить ИИ-ответы.
* **Смена приветствия.** Пришли боту новый пост (например, с актуальным колесом) и нажми «👋 Сделать приветствием» — его будут получать все на `/start` и «Привет». `/welcome` показывает текущее. Приветствие хранится на листе «Настройки бота» в той же Google-таблице, поэтому переживает перезапуски.
* `/send` — ответь этой командой на любое своё сообщение (текст, фото, видео, пост) и выбери: **👥 Всей базе** или **📣 В канал** (`PROMO_CHANNEL_ID`, бот должен быть админом канала). Это и есть «авто-рассылка поста о стриме» из планов на стикере.
* `/stats` — сколько уникальных людей в базе, `/myid` — узнать свой Telegram ID, `/admin` — подсказка.
* Если ИИ прислал битый HTML — сообщение уйдёт без разметки, а не потеряется. Если картинка не грузится — пост уйдёт текстом.
* Флуд-лимиты Telegram обрабатываются автоматически.

Шаблоны рассылок: колесо, итоги розыгрыша, стрим начался, анонс клипа, стрим (серый), моменты со стрима, стрим → в канал `-1001407379425`.
Все тексты, картинки, кнопки и промпт — в `bot/texts.py`. Поменял и запушил → Railway сам передеплоит.

## Мини-приложение

Бот сам раздаёт мини-приложение (папка `webapp/`): казино из актуальных зеркал, колесо бонусов, подбор казино,
калькулятор отыгрыша, гайды с прогрессом, лента постов из каналов и личный кабинет с проверкой подписок.

**Включить (один раз):**
1. Railway → сервис → **Settings → Networking → Generate Domain** (если спросит порт — `8080`).
2. Скопировать адрес вида `https://....up.railway.app` в переменную **`WEBAPP_URL`**.
3. После перезапуска у всех пользователей появится кнопка **«Приложение»** у поля ввода, а кнопки под «⚠️ ВАЖНО» откроют разделы приложения.

**Лента** — посты, которые бот получает из @vtss2 и нашего канала (`PROMO_CHANNEL_ID`) после запуска; хранится на листе «Настройки бота».
**Подписки** в кабинете бот проверяет сам по каналам, где он админ.

**Казино и зеркала обновляются сами** из закрепа «Актуальные зеркала» в сером канале (`MIRRORS_CHANNEL_ID`, по умолчанию = `PROMO_CHANNEL_ID`).
Бот берёт пост, когда его публикуют, редактируют или закрепляют, и дополнительно проверяет закреп раз в 30 минут.
Админам приходит уведомление «Зеркала обновлены», а команда `/mirrors` обновляет список вручную и показывает, когда было последнее обновление.
Формат поста: строка «Название: ссылка», ниже строки с бонусом и кодами вида `КОД — описание`; строка «…проверенные временем» начинает блок проверенных казино.

Править казино и бонусы: `webapp/src/template.html` (массив `CASINOS`); статьи базы знаний: `webapp/src/kb.js`. Затем `python webapp/build.py` — пересоберёт `webapp/index.html`.

Приложение адаптивное: телефон — одна колонка, планшет и компьютер — сетка в 2–5 колонок.

## Автопересылка из канала Витуса

Посты из канала **@vtss2** бот сам публикует в наш канал (`PROMO_CHANNEL_ID`):
медиа (фото / видео / альбом) остаются, из текста берутся первые строки Витуса (например «Хайрольчик пошёл)»),
а служебный блок со ссылками заменяется нашей подписью:

```
Хайрольчик пошёл)

Заходи на стрим: https://kick.com/vituss
Актуальные зеркала казино: https://t.me/vituss2/644
```

**Чтобы заработало:** добавить бота в канал @vtss2 **администратором** (все права можно выключить — бот там ничего не публикует, ему нужно только видеть посты). Без этого Telegram боту посты канала не показывает.

* `REPOST_MODE=auto` — публиковать сразу (по умолчанию).
* `REPOST_MODE=approve` — сначала прислать админам превью с кнопками «✅ Опубликовать», «🔴 Как анонс стрима», «❌ Пропустить».
* `REPOST_MODE=off` — выключить.

Подпись и маркеры служебного блока (`MOMENT_FOOTER`, `BOILERPLATE_MARKERS`) — в `bot/texts.py`.
Всё, начиная с первой строки со ссылкой или строки, которая начинается с «Стрим идёт тут», «Казино», «Подпишись» и т.п., отбрасывается.

## Пересылки между каналами (/reposts)

| Пересылка | Откуда | Куда | Как выглядит пост |
|---|---|---|---|
| Канал Витуса | @vtss2 (`SOURCE_CHANNEL`) | канал ВИТУС (`PROMO_CHANNEL_ID`) | фраза Витуса + наша подпись |
| Профит Хата | @profithata777 (`PROFIT_SOURCE`) | группы, выбранные в /reposts | как в оригинале: текст, форматирование, фото, видео, альбомы, без «переслано» |

* Бот должен быть **админом и в канале-источнике, и в каждом канале/группе, куда пересылает**.
* Бот запоминает канал или группу, когда видит там любое сообщение. Чтобы группа сразу появилась, напиши в ней `/bind`; в канале опубликуй `/bind` (бот удалит это сообщение сам) или перешли боту любой пост из этого канала.
* `/reposts` → выбери пересылку → «📍 Куда пересылать» → отметь группы галочками. Там же режим: «сразу», «после проверки админом» (бот присылает превью с кнопками) или «выключена».
* Настройки хранятся на листе «Настройки бота» и переживают перезапуски.

### Посты в группах — от имени группы, а не бота (`/userbot`)

Бот в группе всегда пишет от своего имени: право «Анонимность» на ботов не действует.
Поэтому посты «как есть» (Профит Хата) в **группы** бот отправляет через обычный аккаунт Telegram —
«аккаунт-публикатор». Он админ с **«Анонимностью»**, и Telegram подписывает его сообщения названием группы.
Пост копируется без «Переслано из…»: текст, форматирование, медиа, кнопки-ссылки и альбомы сохраняются.
В каналы бот и так публикует от имени канала — там аккаунт не нужен.

1. https://my.telegram.org → войти аккаунтом-публикатором → **API development tools** → создать приложение
   (название любое, платформа Other) → `App api_id` и `App api_hash` в Railway: `USERBOT_API_ID`, `USERBOT_API_HASH`.
2. Аккаунт — **админ с «Анонимностью»** во всех группах пересылки (права публиковать сообщения достаточно).
3. В личке бота `/userbot` → «🔐 Войти» → номер → код **цифрами через пробел** (`1 2 3 4 5`, иначе Telegram отменит код)
   → пароль двухэтапной проверки, если есть (бот сразу удаляет сообщения с кодом и паролем).
4. Бот пришлёт строку сессии — вставить в Railway как `USERBOT_SESSION`, чтобы вход пережил перезапуски
   (сообщение со строкой бот удалит через 10 минут). Это ключ от аккаунта — никому не показывать.
5. `/userbot` → «🧪 Проверить группы» — ✅ у каждой группы, где аккаунт админ с «Анонимностью».

Если в какой-то группе аккаунт не админ или не анонимен, бот отправит пост сам (от своего имени) и предупредит админов.

## Музыкальная группа: YouTube → Google Диск

Виктор кидает в группу ссылку на YouTube — бот ставит 👀 на его сообщение и отвечает **карточкой-картинкой**,
которую сам рисует и перерисовывает на каждом этапе: размытая обложка, винил, чистое название и исполнитель, бейджи
(1080p · длительность · размер · качество звука), хэштеги жанров и «путь трека»
`YouTube → Скачано → Google Диск → ВКонтакте` — пройденные шаги зелёные с временем, текущий светится золотом.

В подписи — проценты скачивания/загрузки, раскрывающийся блок с деталями файлов и «Путь трека» со временем
каждого шага (прислал → скачано → на Диске → взял в работу → выложено).

Кнопки готовой карточки (цветные):
`📁 Открыть папку на Диске` · `🎬 Видео со звуком` · `🎧 Только звук` · `🔊 Послушать здесь` · `▶️ YouTube` ·
`📋 Скопировать текст для ВК` (название + хэштеги в буфер обмена) · `🛠 Беру в работу` → `✅ Выложил в ВК`.

Реакции на сообщении Виктора: 👀 принято → 🔥 готово → 🏆 выложено в ВК (😢 — если не получилось).

* **Качество.** «Видео со звуком» — один MP4, где картинка и звук вместе (лучшее до 1080p, H.264 + AAC, открывается везде, в машине тоже), дорожки склеиваются без пережатия.
  Звук — отдельный файл, оригинальная дорожка YouTube без пережатия (лучше, чем у YouTube, не бывает).
  `MUSIC_AUDIO=best` — брать Opus, если он есть (чуть лучше, но хуже открывается на iPhone/Windows).
* **Название** чистится: `LIQUID DOGMA (द्रवसिद्धान्त) | Full Album (Psybient & Organic Downtempo) - Liquid Dunes` → **LIQUID DOGMA** · Liquid Dunes · #fullalbum #psybient #organicdowntempo.
* **Диск:** `Музыка Витуса / 2026-11 / Исполнитель — Название /` — видео, звук и обложка. Папка трека открыта по ссылке.
* **Дубли:** повторная ссылка не качается заново — бот сразу отдаёт готовую папку.
* **Плейлист** по ссылке `playlist?list=…` раскрывается (а трек из микса `watch?v=…&list=…` — качается только он): каждое видео (до 50) — своя карточка. Видео длиннее 90 минут и эфиры пропускаются (`MUSIC_MAX_MINUTES`).
* **Карточка-«приложение»:** обложка трека, цветные кнопки, строка статуса `✅ Скачано · ✅ На Диске · ⏳ ВК`.
* **ВК в два шага:** «🛠 Беру в работу» → «✅ Выложил в ВК» (жмёт публикатор, админ бота или админ группы).
  После публикации в карточке остаётся «✅ В ВК выложил Александр · 17.11 14:05», а Виктору приходит «🎉 трек уже в ВК».
  Ошиблись — «↩️ Снять отметку ВК».
* **«🔊 Послушать здесь»** — бот присылает звук прямо в чат (с Диска), второй раз — мгновенно.
* **`/todo`** в группе — список треков, которые ещё не выложены в ВК, со ссылками на карточки.
* Тегается тот, кто прислал ссылку (Виктор), и публикатор (Александр, задаётся `/publisher`).
* **Учёт:** каждый трек записывается на лист «Музыка» в Google-таблице (дата, кто прислал, ссылки, отметка ВК).
* Ошибка — карточка с причиной и кнопкой «🔁 Попробовать снова»; если дело в YouTube или Диске — бот пишет админам.

**Настройка группы (2 минуты):**
1. Добавить бота в группу и сделать **администратором** (права можно все выключить) — иначе Telegram не показывает боту обычные сообщения.
2. Написать в группе `/musichere` (может админ бота или админ группы). Выключить — `/musicoff`.
3. Ответить командой `/publisher` на любое сообщение Александра (или `/publisher @username`) — его бот будет тегать для ВК.
4. В личке бота `/music` — всё ли подключено.
5. `/redraw` ответом на старую карточку — перерисовать её в новом дизайне (без ответа — все карточки группы).

### Google Диск (один раз, ~10 минут)

У сервисного аккаунта нет места на Диске, поэтому бот загружает от имени обычного аккаунта Google (через вход OAuth).
Бот получает доступ **только к файлам, которые создал сам** (`drive.file`), остальной Диск ему не виден.

1. https://console.cloud.google.com → тот же проект, что и для таблицы → **APIs & Services → Library → Google Drive API → Enable**.
2. **Google Auth Platform → Branding**: название (например «Бот Витус»), support email,
   **App home page** = `WEBAPP_URL`, **Privacy policy** = `WEBAPP_URL/privacy` (страницу отдаёт сам бот), Save. Тип — **External**.
   Проект Google Cloud может быть на любом аккаунте: Диск выбирается при входе через `/gdrive`.
   Затем **Audience → Publish app** (статус «In production») — иначе вход «слетает» через 7 дней. Проверка Google для `drive.file` не нужна.
3. **Clients → Create client → Web application** → **Authorized redirect URIs**: `https://<адрес из WEBAPP_URL>/oauth/google`.
4. Client ID и Client secret → Railway Variables: `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`.
5. В боте `/gdrive` → «🔐 Войти через Google» → выбрать аккаунт, на чей Диск складывать музыку
   (на экране «Google не проверил приложение» → «Дополнительно» → «Перейти»). Бот пришлёт «✅ Google Диск подключён» и ссылку на папку.

Место: 4-минутный клип в 1080p ≈ 60–150 МБ, бесплатные 15 ГБ ≈ 100–200 треков. Для большего — Google One на том же аккаунте.

### Если YouTube не отдаёт видео

YouTube часто не отдаёт файлы серверам дата-центров (Railway в их числе): «Sign in to confirm you're not a bot».
Бот тогда напишет админам. Решение:

* **`YOUTUBE_COOKIES`** — cookies **запасного** Google-аккаунта (не основного: YouTube может его ограничить).
  В браузере войти этим аккаунтом на youtube.com → расширение «Get cookies.txt LOCALLY» → Export (формат Netscape)
  → весь текст файла вставить в переменную (можно в base64). Cookies живут недели-месяцы; когда протухнут — бот снова напишет.
* **`YOUTUBE_PROXY`** — если и с cookies не пускает: домашний/резидентный прокси, `http://логин:пароль@хост:порт`.

## Секреты (переменные окружения)

Секреты **не хранятся в репозитории** — они задаются в Railway → сервис → **Variables** (шаблон в `.env.example`).
Из экспорта n8n ключи достать нельзя (там только ID кредов), поэтому их нужно вставить один раз вручную.

| Переменная | Обязательно | Где взять |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | @BotFather → твой бот → API Token (тот же бот, что в n8n) |
| `OPENAI_API_KEY` | да | https://platform.openai.com/api-keys |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | да* | JSON-ключ сервисного аккаунта Google (см. ниже) |
| `ADMIN_IDS` | да | твой Telegram ID (напиши боту `/myid`), несколько — через запятую |
| `SPREADSHEET_ID` | нет | по умолчанию таблица «База игроков» `16GFYOAe74YSPDDMLGPxvKjFS0d6heVbvs7VgUs_-Tnw` |
| `SHEET_GID` | нет | `0` — лист «Основная база» |
| `OPENAI_MODEL`, `OPENAI_MAX_TOKENS`, `OPENAI_TEMPERATURE`, `MEMORY_WINDOW` | нет | `gpt-4o-mini`, `200`, `0.7`, `5` |
| `FOLLOWUP_DELAY` | нет | `10` — задержка перед «⚠️ ВАЖНО!» |
| `PROMO_CHANNEL_ID` | нет | `-1001407379425` — наш канал |
| `SOURCE_CHANNEL` | нет | `vtss2` — канал Витуса, откуда пересылать посты |
| `REPOST_MODE` | нет | `auto` / `approve` / `off` |
| `WEBAPP_URL` | для мини-приложения | публичный адрес сервиса Railway |
| `PROFIT_SOURCE` | нет | `profithata777` — канал Профит Хата |
| `PROFIT_REPOST_MODE` | нет | `auto` — режим по умолчанию (дальше меняется в /reposts) |
| `MIRRORS_CHANNEL_ID` | нет | канал с закрепом «Актуальные зеркала» (по умолчанию `PROMO_CHANNEL_ID`) |

| `MUSIC_DRIVE_FOLDER` | нет | `Музыка Витуса` — корневая папка на Диске |

| `YOUTUBE_PROXY` | нет | прокси для YouTube |
| `USERBOT_API_ID`, `USERBOT_API_HASH` | для постов «от группы» | my.telegram.org → API development tools |
| `USERBOT_SESSION` | для постов «от группы» | бот пришлёт после входа через `/userbot` |
| `MUSIC_AUDIO`, `MUSIC_MAX_HEIGHT`, `MUSIC_MAX_MINUTES` | нет | `m4a` / `best`, `1080`, `90` |

\* без него бот отвечает, но не пишет в таблицу и не делает рассылки.

### Google-таблица (сервисный аккаунт, 5 минут)

1. https://console.cloud.google.com → создать проект (или взять любой).
2. **APIs & Services → Library** → включить **Google Sheets API**.
3. **IAM & Admin → Service Accounts → Create** → любое имя → **Keys → Add key → JSON** — скачается файл.
4. Открыть таблицу «База игроков» → **Поделиться** → вставить `client_email` из JSON (вида `...@...iam.gserviceaccount.com`) → роль **Редактор**.
5. Весь текст JSON-файла вставить в Railway в переменную `GOOGLE_SERVICE_ACCOUNT_JSON` (можно и в base64).

## Деплой на Railway

1. https://railway.com → **New Project → Deploy from GitHub repo** → выбрать этот репозиторий.
2. В сервисе → **Variables** → добавить переменные из таблицы выше (удобно через **Raw Editor**, вставив `.env.example` с заполненными значениями).
3. Railway сам поставит Python, зависимости из `requirements.txt` и запустит `python -m bot` (см. `railway.json`). Домен/порт не нужен — бот работает через long polling.
4. **Выключи воркфлоу в n8n** (Active → off). Иначе n8n снова поставит свой вебхук и будет перехватывать сообщения. Бот при старте сам снимает вебхук n8n.
5. В логах Railway должно появиться `Бот @... запущен`. Напиши боту `/start`.

Держи ровно **1 реплику** — два запущенных экземпляра с одним токеном конфликтуют.

## Локальный запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить
set -a; source .env; set +a
python -m bot
```

## Структура

```
bot/
  __main__.py   запуск, снятие вебхука, polling
  handlers.py   сценарий общения + админка рассылок
  ai.py         OpenAI + память диалога
  sheets.py     Google Sheets: запись сообщений, чтение базы
  broadcast.py  рассылки с отчётом
  sender.py     отправка с защитой от ошибок Telegram
  texts.py      все тексты, картинки, кнопки, промпт
  config.py     переменные окружения
  music/        музыкальная группа: youtube.py (скачивание), gdrive.py (Диск), service.py (очередь, карточки, команды)
```

Память диалога хранится в оперативке (как Simple Memory в n8n) и сбрасывается при перезапуске.
