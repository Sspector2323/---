Доступы к компьютеру (Windows)

  1. Микрофон. Пуск → Параметры → Конфиденциальность и защита → Микрофон → включите «Доступ к микрофону» и «Разрешить классическим приложениям доступ к микрофону».
  2. Полный доступ (права администратора). Без них Джарвис делает всё от вашего имени, но не может управлять окнами, запущенными от администратора, и выполнять системные команды. Чтобы дать полный доступ: правой кнопкой по start_jarvis.bat → «Запуск от имени администратора».
  3. Без лишних вопросов. В поле «Спрашивать да/нет…» выше выберите false — тогда выключение ПК, удаление файлов, письма и команды терминала он будет выполнять сразу. Рекомендуем оставить true, хотя бы первое время.
  4. Почта. Нужен не обычный пароль, а «пароль приложения»: Gmail · Яндекс · Mail.ru: Настройки → Безопасность → Пароли для внешних приложений.
  5. Файлы. Джарвис видит все ваши папки (рабочий стол, загрузки, документы и любые другие) — отдельно ничего давать не нужно.
  6. Большие задачи через Claude Code. Установите Claude Code (инструкция в README), и Джарвис сможет поручать ему сложные задачи.
