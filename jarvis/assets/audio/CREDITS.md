# Музыка

Все три трека — **Kevin MacLeod** (incompetech.com), лицензия **Creative Commons Attribution 4.0**
(http://creativecommons.org/licenses/by/4.0/). Взяты из открытого проекта adewaskar/jarvis.

| Файл | Трек | Где звучит |
|---|---|---|
| `boot-music.mp3` | *Impact Prelude* | при запуске, вместе с анимацией |
| `ambient.mp3` | *Ossuary 6 – Air* | тихий фон при запуске |
| `work.mp3` | *Mechanolith* | тихо, пока идёт долгая задача (если MUSIC=all) |

Если будете публиковать видео с Джарвисом, добавьте в описание:

```
Music by Kevin MacLeod (incompetech.com)
"Impact Prelude", "Ossuary 6 - Air", "Mechanolith"
Licensed under Creative Commons: By Attribution 4.0
```

Свою музыку можно положить в `data/music/` с теми же именами файлов — она заиграет вместо этой.
