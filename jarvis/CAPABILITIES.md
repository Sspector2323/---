# Что умеет Джарвис

> «Моё почтение, Сабина. Я к вашим услугам.» При запуске Джарвис появляется анимацией на всех мониторах, здоровается и коротко рассказывает, что сегодня: погода, дела, проекты, почта.

Говорите «**Джарвис**» и команду своими словами. Точные формулировки не нужны: Джарвис сам понимает, что сделать, и может выполнить несколько действий подряд. 8 секунд после его ответа можно продолжать без слова «Джарвис».

Действия со значком ⚠️ он выполняет только после вашего «да». Проверку можно отключить в `.env`: `CONFIRM_DANGEROUS=false`.

## 📊 Дашборд (http://localhost:5050)
Открывается сам после анимации или по команде «Джарвис, открой дашборд». Кликается всё: проекты, письма, задачи Notion, быстрые кнопки, микрофон в браузере. Что там есть:
- загрузка процессора, памяти и диска, заряд батареи;
- задачи: добавлять, отмечать и удалять можно мышкой;
- напоминания, заметки, последние письма;
- что Джарвис о вас помнит;
- журнал разговора;
- поле для текстовых команд, если говорить вслух неудобно.

## 🧠 Режим «Джарвис + Claude Code»
Если в настройках выбран мозг `claude_code`, Джарвис говорит голосом, а думает и действует Claude Code на вашем компьютере. В этом режиме работают все умения из этого списка. Кроме них Claude сам читает и правит файлы, выполняет команды, ищет в интернете и пишет программы. Всё идёт по подписке Claude, без API-ключа.

## 🤖 Сложные задачи через Claude Code
Если на компьютере установлен Claude Code (см. README), Джарвис поручает ему большие многошаговые задачи. Claude Code сам пишет код, правит файлы и запускает команды.
| Умение | Пример фразы |
|---|---|
| ⚠️ Сделать сайт, скрипт, программу | «Джарвис, сделай мне сайт-визитку в папке Documents/site» |
| ⚠️ Навести порядок в проекте или папке | «Джарвис, почини мой бот в папке projects/bot» |
| ⚠️ Автоматизировать рутину | «Джарвис, напиши скрипт, который каждый день чистит загрузки» |

## Честно о границах
- **Интернет нужен всегда.** Через него работают мозг (GPT или Claude), распознавание речи (Google) и красивый голос. Без сети Джарвис переключается на простой встроенный голос, но команды понимать не сможет.
- **Включить выключенный компьютер голосом нельзя**, потому что Джарвис живёт внутри компьютера. Можно настроить автозапуск: включили ПК, и Джарвис сразу слушает.
- **Календарь Google, Telegram, умный дом** пока не подключены. Их можно добавить следующим шагом.
- **Приватность.** Чтобы уловить слово «Джарвис», программа отправляет услышанные фразы на распознавание в Google. Мозгу (OpenAI или Claude) и в журнал попадают только команды, обращённые к Джарвису.
