# J.A.R.V.I.S. — голосовой ИИ-ассистент для вашего компьютера

Говорите «**Джарвис**» и команду, он отвечает голосом и выполняет. Под капотом **Claude**: он понимает речь по смыслу, а не по шаблонам. Джарвис ведёт личные дела, разбирает почту, показывает дашборд и управляет компьютером вплоть до выключения.

📋 **Полный список умений: [CAPABILITIES.md](CAPABILITIES.md)**

---

## Часть 1. Установка Джарвиса (Windows, ~10 минут)

### Что понадобится
- компьютер с микрофоном и колонками или наушниками;
- интернет;
- **ключ Claude API**. Получить его на https://console.anthropic.com: зарегистрироваться → Billing (пополнить баланс, хватит $5–10 для начала) → **API Keys** → Create Key. Ключ начинается с `sk-ant-`.

### Шаги
1. **Установите Python 3.12** с https://www.python.org/downloads/.
   ⚠️ В первом окне установщика отметьте галочку **«Add python.exe to PATH»**.
2. **Скачайте Джарвиса**: на странице репозитория на GitHub нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив, например в `C:\Jarvis`. Нужна папка `jarvis` внутри архива.
3. Откройте папку `jarvis` и дважды кликните **`install_windows.bat`**. Он сам поставит всё нужное, это займёт пару минут.
4. В конце откроется Блокнот с настройками `.env`:
   - вставьте ключ в строку `ANTHROPIC_API_KEY=`;
   - укажите свой город в `CITY=` и как к вам обращаться в `USER_NAME=`;
   - для почты заполните `EMAIL_ADDRESS` и `EMAIL_PASSWORD` (ниже написано, где взять пароль);
   - сохраните файл (Ctrl+S).
5. Запустите **`start_jarvis.bat`**. Откроется дашборд, а Джарвис скажет «Джарвис на связи».
6. Скажите: **«Джарвис, привет!»**

**Автозапуск вместе с Windows:** дважды кликните `add_to_startup.bat`.

**Без микрофона:** запустите `start_jarvis_text.bat` и печатайте команды в окне. Ещё можно писать в поле «Команда» на дашборде.

### Почта: где взять пароль
Обычный пароль от почты не подойдёт, нужен **пароль приложения**:
- **Gmail:** включите двухэтапную проверку → https://myaccount.google.com/apppasswords → создайте пароль → вставьте его в `EMAIL_PASSWORD` (без пробелов).
- **Яндекс:** https://id.yandex.ru/security/app-passwords → «Почта». В настройках почты включите доступ по IMAP.
- **Mail.ru:** Настройки → Безопасность → «Пароли для внешних приложений».

### Mac / Linux
```bash
cd jarvis
./install_mac_linux.sh
# вставьте ключ в .env, затем:
source .venv/bin/activate && python main.py
```
На Mac при первом запуске разрешите доступ к микрофону и «Универсальный доступ» для Терминала. Без этого Джарвис не сможет нажимать клавиши и регулировать звук.

## Часть 2. Установка Claude Code (меня) на компьютер

**Claude Code** — это я, тот же Claude, с которым вы сейчас говорите, только работающий прямо на вашем компьютере. Я вижу ваши файлы, запускаю программы, пишу и чиню код. Джарвис умеет передавать мне большие задачи сам: «Джарвис, сделай мне сайт…».

Нужна подписка **Claude Pro/Max** (вход через claude.ai) или баланс в Console.

**Windows:** откройте **PowerShell** (Пуск → введите «PowerShell») и выполните:
```powershell
irm https://claude.ai/install.ps1 | iex
```
**Mac / Linux:** в Терминале:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
Потом в любой папке наберите `claude`, войдите в аккаунт и пишите задачи по-русски.

Если командная строка не по душе, есть приложение **Claude для компьютера**: https://claude.ai/download. В нём есть вкладка Code, где работает тот же Claude Code.

## Как это устроено

```
микрофон → распознавание речи (Google) → «Джарвис?» → Claude (мозг) ⇄ инструменты → голос (edge-tts)
                                                        │
                                          задачи / почта / ПК / файлы / интернет
                                                        │
                                            SQLite (data/jarvis.db) → дашборд :5050
```

| Файл | Что внутри |
|---|---|
| `main.py` | запуск, голосовой цикл, слово-активатор, напоминания |
| `core/brain.py` | Claude и цикл вызова инструментов |
| `core/voice.py` | слух и голос |
| `core/tools/*.py` | умения: `system` (ПК), `files`, `tasks` (дела), `mail`, `info`, `claude_code` |
| `core/dashboard.py`, `core/web/index.html` | дашборд |
| `data/` | ваша база: задачи, заметки, память, журнал. Хранится только у вас на компьютере |

**Добавить новое умение** — написать функцию с декоратором `@tool(...)` в любом файле `core/tools/`. Claude сам поймёт, когда её вызывать.

### Настройки `.env`
| Параметр | Что делает |
|---|---|
| `JARVIS_MODEL` | модель Claude (по умолчанию `claude-opus-5`) |
| `JARVIS_EFFORT` | `low` — быстрые ответы (по умолчанию), `medium`/`high` — глубже думает, но медленнее |
| `WAKE_WORDS` | слова-активаторы через запятую |
| `TTS_VOICE` | голос: `ru-RU-DmitryNeural` (мужской) или `ru-RU-SvetlanaNeural` (женский) |
| `CONFIRM_DANGEROUS` | спрашивать ли «да/нет» перед выключением ПК, письмами, удалением файлов |

Если основная модель откажется выполнить запрос, он автоматически уходит на запасную модель Claude (параметр `fallbacks`).

### Сколько стоит
Джарвис платит за Claude API по факту использования. Обычная команда стоит около 1–5 центов. При активном использовании выходит примерно $5–20 в месяц. Распознавание речи, голос, погода и курсы бесплатны.

### Если что-то не работает
| Проблема | Решение |
|---|---|
| `pip install` ругается на PyAudio | поставьте Python **3.12** (не 3.14) и запустите `install_windows.bat` заново |
| Джарвис не слышит | Параметры Windows → Конфиденциальность → Микрофон → разрешить приложениям; проверьте микрофон по умолчанию |
| Реагирует на телевизор или шум | говорите ближе к микрофону; можно сменить слово-активатор в `WAKE_WORDS` |
| «Ключ Claude не подходит» | проверьте `ANTHROPIC_API_KEY` в `.env` и баланс в Console |
| Почта: ошибка входа | нужен пароль приложения, а не обычный пароль; включите IMAP в настройках почты |
