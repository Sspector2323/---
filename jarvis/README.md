# J.A.R.V.I.S. — голосовой ИИ-ассистент для вашего компьютера

Говорите «**Джарвис**» и команду, он отвечает голосом и выполняет. Под капотом **OpenAI (GPT)** или **Claude**, выбирается одной строкой в настройках. Мозг понимает речь по смыслу, а не по шаблонам. Джарвис ведёт личные дела, разбирает почту, показывает дашборд и управляет компьютером вплоть до выключения.

📋 **Полный список умений: [CAPABILITIES.md](CAPABILITIES.md)**

---

## Часть 1. Установка Джарвиса (Windows, ~10 минут)

### Что понадобится
- компьютер с микрофоном и колонками или наушниками;
- интернет;
- **ключ OpenAI API**. Получить его на https://platform.openai.com: Billing (пополнить баланс, хватит $5–10 для начала) → **API keys** → Create new secret key. Ключ начинается с `sk-`. Подойдёт тот же ключ, что у бота Витус.
  Если хотите мозг на Claude, возьмите ключ на https://console.anthropic.com и укажите в `.env` `AI_PROVIDER=claude`.

### Шаги
1. **Установите Python 3.12** с https://www.python.org/downloads/.
   ⚠️ В первом окне установщика отметьте галочку **«Add python.exe to PATH»**.
2. **Скачайте Джарвиса**: на странице репозитория на GitHub нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив, например в `C:\Jarvis`. Нужна папка `jarvis` внутри архива.
3. Откройте папку `jarvis` и дважды кликните **`install_windows.bat`**. Он сам поставит всё нужное, это займёт пару минут.
4. В конце откроется Блокнот с настройками `.env`:
   - вставьте ключ в строку `OPENAI_API_KEY=`;
   - укажите свой город в `CITY=` и как к вам обращаться в `USER_NAME=`;
   - для почты заполните `EMAIL_ADDRESS` и `EMAIL_PASSWORD` (ниже написано, где взять пароль);
   - сохраните файл (Ctrl+S).
5. Запустите **`start_jarvis.bat`**. Откроется дашборд, а Джарвис скажет «Джарвис на связи».
6. Скажите: **«Джарвис, привет!»**

**Автозапуск вместе с Windows:** дважды кликните `add_to_startup.bat`.

**Без микрофона:** запустите `start_jarvis_text.bat` и печатайте команды в окне. Ещё можно писать в поле «Команда» на дашборде.

### Почта: где взять пароль
Обычный пароль от почты не подойдёт, нужен **пароль приложения**:
- **Gmail:** включите двухэтапную проверку → https://myaccount.google.com/apppasswords → создайте пароль → вставьте его в `EMAIL_PASSWORD` (без пробелов).
- **Яндекс:** https://id.yandex.ru/security/app-passwords → «Почта». В настройках почты включите доступ по IMAP.
- **Mail.ru:** Настройки → Безопасность → «Пароли для внешних приложений».

### Mac / Linux
```bash
cd jarvis
./install_mac_linux.sh
# вставьте ключ OPENAI_API_KEY в .env, затем:
source .venv/bin/activate && python main.py
```
На Mac при первом запуске разрешите доступ к микрофону и «Универсальный доступ» для Терминала. Без этого Джарвис не сможет нажимать клавиши и регулировать звук.

## Часть 2. Установка Claude Code (меня) на компьютер

**Claude Code** — это я, тот же Claude, с которым вы сейчас говорите, только работающий прямо на вашем компьютере. Я вижу ваши файлы, запускаю программы, пишу и чиню код. Джарвис умеет передавать мне большие задачи сам: «Джарвис, сделай мне сайт…».

Нужна подписка **Claude Pro или Max** (бесплатный тариф claude.ai не подходит) или аккаунт Console с балансом.

**Windows:** откройте **PowerShell** (Пуск → введите «PowerShell») и выполните:
```powershell
irm https://claude.ai/install.ps1 | iex
```
**Mac / Linux:** в Терминале:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
Когда установка закончится, **закройте PowerShell и откройте заново**, затем:
```powershell
claude --version   # должна показаться версия — значит, установилось
claude             # запуск: откроется браузер, войдите в аккаунт Claude
```
Дальше просто пишите задачи по-русски. Права администратора не нужны. По желанию поставьте [Git for Windows](https://git-scm.com/downloads/win) — с ним Claude Code работает чуть лучше.

Если PowerShell пишет, что `claude` не найден, — перезагрузите компьютер. Если установка ругается, в **cmd** (не PowerShell) можно так:
```
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

Если командная строка не по душе, есть приложение **Claude для компьютера**: https://claude.ai/download. В нём есть вкладка Code, где работает тот же Claude Code.

## Часть 3. Связать Джарвиса с Claude Code (рекомендуется)

В этом режиме мозг Джарвиса — **Claude Code на вашем компьютере**. Голосовая оболочка остаётся та же, а думает и действует Claude. Ключ API не нужен, всё идёт по подписке Claude Pro/Max.

1. Установите Claude Code и войдите в аккаунт (Часть 2). Проверка: в PowerShell `claude --version` показывает версию.
2. В дашборде откройте **⚙ Настройки** → «Чей мозг» → `claude_code` → Сохранить.
3. Перезапустите Джарвиса.

Что умеет Claude в этом режиме:
- **все умения Джарвиса**: дела, напоминания, почта, звук, музыка, программы, выключение ПК. Они подключены к Claude Code как инструменты (MCP);
- **свои умения Claude Code**: читать и править любые файлы, выполнять команды, искать в интернете, писать программы;
- **помнит разговор**, пока вы не скажете «новый диалог».

Безопасность: читать файлы и искать в интернете Claude может без вопросов. Перед командами терминала, записью файлов, выключением ПК или отправкой писем Джарвис спросит вас голосом «да или нет». Отключается в ⚙ Настройках.

Модель: пусто — по умолчанию из подписки. Если хочется быстрее, впишите `sonnet` или `haiku` в «Модель Claude Code». Простая команда обычно занимает 4–10 секунд. Мгновенные команды (время, громкость, пауза) по-прежнему выполняются сразу.

## Часть 4. Notion, GitHub и «вместе с Claude в облаке»

### Notion (≈3 минуты)
1. Откройте https://www.notion.so/profile/integrations → **New integration** → тип Internal, имя «Джарвис» → Save → скопируйте **Internal Integration Secret**.
2. В Notion откройте базу **«Сводка задач»** → ••• (справа вверху) → **Подключения** → найдите «Джарвис» → Подтвердить. То же самое для страницы **«J.A.R.V.I.S. — общий штаб»**.
3. Дашборд → ⚙ Настройки → «Notion: секрет интеграции» → вставить → Сохранить → перезапустить Джарвиса.

### GitHub (≈3 минуты)
1. Откройте https://github.com/settings/personal-access-tokens/new, задайте имя «Джарвис» и срок действия.
2. Repository access: **All repositories**. Permissions → Repository: **Contents, Pull requests, Issues, Actions** → *Read-only*.
3. Нажмите Generate token → скопируйте токен → ⚙ Настройки → «GitHub: токен» → Сохранить → перезапустить.
4. Скажите «Джарвис, скачай все репозитории». Они появятся в папке проектов (по умолчанию `C:\Users\вы\Projects`), и заработает «открой таймкодер».

### Вместе с Claude в облаке
- **Общий штаб в Notion.** Его ведут и Джарвис («Джарвис, запиши в штаб…»), и Claude в облаке. Любому из них можно сказать «посмотри штаб».
- **Работа облачного Claude** видна на дашборде в панели «Claude в облаке»: его ветки `claude/…` и PR во всех репозиториях.
- **Сессии Claude Code с компьютера в приложении Claude.** В PowerShell, в папке проекта, выполните `claude remote-control`. Сессия с компьютера появится в приложении Claude (раздел Code) рядом с облачными, и ею можно управлять с телефона.

## Часть 5. Джарвис в Cursor и Codex

Идея: один Джарвис на все инструменты. В Cursor и Codex у ИИ появляются умения Джарвиса: задачи Notion, штаб, GitHub, дела, почта, управление ПК. Итоги работы они пишут в общий штаб.

1. Установите **Cursor**: https://cursor.com. В Cursor: Ctrl+Shift+P → «Install 'cursor' command».
2. Установите **Codex CLI**. Нужен Node.js (https://nodejs.org). В PowerShell:
   ```powershell
   npm install -g @openai/codex
   codex login
   ```
3. Запустите **`connect_editors.bat`** в папке `jarvis`. Он сам пропишет Джарвиса в Cursor (`~/.cursor/mcp.json`) и Codex (`~/.codex/config.toml` + `AGENTS.md`) и скопирует правила для Cursor в буфер. Их нужно вставить в Cursor → Settings → Rules → User Rules.
4. Перезапустите Cursor и Codex. На дашборде в «Подключениях» они загорятся зелёным.

Голосом: «Джарвис, **открой таймкодер в Курсоре**», «Джарвис, **поручи Кодексу** в дайс боте добавить команду /help». Опасные действия из Cursor и Codex (выключить ПК, отправить письмо и т. п.) подтверждаются голосом через запущенного Джарвиса. Если он выключен, такие действия запрещены.

## Часть 6. Появление, приветствие, дашборд

- **Анимация на всех мониторах.** При запуске Джарвис разворачивается на каждом мониторе в собственных окнах (движок WebView2, встроен в Windows): реактор, частицы, проверка систем. На главном мониторе появляется «Моё почтение, Сабина. Я к вашим услугам.». Клик или любая клавиша пропускает анимацию. Отключается в ⚙ Настройках.
- **Интерфейс на всех мониторах.** После анимации дашборд раскладывается по экранам: на главном всё, на левом «Работа» (проекты, Notion, Claude, подключения), на правом «Личное» (дела, почта, напоминания, журнал). Голосом: «Джарвис, разверни интерфейс на все экраны». В ⚙ Настройках можно оставить только главный монитор.
- **Приветствие и сводка дня.** Джарвис говорит приветствие, затем коротко: погода, дела на сегодня, проекты в работе, новые письма. Текст приветствия меняется в ⚙ Настройках.
- **Дашборд** (http://localhost:5050), на нём кликается всё:
  - строка команд с микрофоном (можно говорить прямо в браузере) и подсказками;
  - быстрые кнопки: рабочая зона, почта, громкость, музыка, блокировка, сон, выключение (с подтверждением);
  - кольца загрузки ПК и график процессора, статус подключений (Claude Code, Cursor, Codex, Notion, GitHub, почта);
  - дела, напоминания (с выбором времени), заметки, память;
  - проекты GitHub: клик открывает карточку с кнопками «Открыть в Cursor», «VS Code», «Поручить Codex…», «Поручить Claude…», коммитами и PR;
  - Notion: статусы меняются прямо на дашборде, новые задачи добавляются в базу;
  - почта: письмо открывается кнопкой, есть «Ответить», «Пересказать», «В задачи», «Удалить»;
  - журнал разговора в виде чата. Работает и на телефоне в той же сети.

## Как это устроено

```
микрофон → распознавание речи (Google) → «Джарвис?» → GPT/Claude (мозг) ⇄ инструменты → голос (edge-tts)
                                                        │
                                          задачи / почта / ПК / файлы / интернет
                                                        │
                                            SQLite (data/jarvis.db) → дашборд :5050
```

| Файл | Что внутри |
|---|---|
| `main.py` | запуск, голосовой цикл, слово-активатор, напоминания |
| `core/brain_claude_code.py`, `core/mcp_server.py` | мозг = Claude Code; умения Джарвиса для него (MCP) |
| `core/brain_openai.py`, `core/brain.py` | мозг на OpenAI и на Claude API: цикл вызова инструментов |
| `core/voice.py` | слух и голос |
| `core/tools/*.py` | умения: `system` (ПК), `files`, `tasks` (дела), `mail`, `info`, `claude_code`, `notion`, `github`, `workspace` |
| `core/dashboard.py`, `core/web/index.html` | дашборд |
| `core/intro.py`, `core/web/intro.html` | анимация появления на всех мониторах |
| `core/integrations.py`, `connect_editors.bat` | подключение к Cursor и Codex |
| `core/briefing.py` | сводка дня при запуске |
| `data/` | ваша база: задачи, заметки, память, журнал. Хранится только у вас на компьютере |

**Добавить новое умение** — написать функцию с декоратором `@tool(...)` в любом файле `core/tools/`. Мозг сам поймёт, когда её вызывать.

### Настройки `.env`
| Параметр | Что делает |
|---|---|
| `AI_PROVIDER` | `claude_code` (Claude Code по подписке), `openai` или `claude` (API) |
| `CLAUDE_CODE_MODEL` | модель для `claude_code`: пусто = по подписке, `sonnet`/`haiku` — быстрее |
| `OPENAI_MODEL` | модель GPT: `gpt-4.1` (по умолчанию) или дешевле `gpt-4.1-mini` |
| `JARVIS_MODEL` | модель Claude, если выбран Claude (по умолчанию `claude-opus-5`) |
| `JARVIS_EFFORT` | для Claude: `low` — быстрые ответы (по умолчанию), `medium`/`high` — глубже думает, но медленнее |
| `WAKE_WORDS` | слова-активаторы через запятую |
| `TTS_VOICE` | голос: `ru-RU-DmitryNeural` (мужской) или `ru-RU-SvetlanaNeural` (женский) |
| `CONFIRM_DANGEROUS` | спрашивать ли «да/нет» перед выключением ПК, письмами, удалением файлов |

Разница между мозгами: у Claude есть встроенный поиск в интернете (свежие новости, цены). У GPT его нет, а все остальные умения одинаковые.

### Сколько стоит
Мозг оплачивается по факту использования. На `gpt-4.1` команда стоит около 1–3 центов, на `gpt-4.1-mini` в несколько раз дешевле. При активном использовании выходит примерно $3–15 в месяц. Распознавание речи, голос, погода и курсы бесплатны.

### Скорость ответа
В чёрном окне после каждой команды видно, сколько занял каждый этап: `⏱ распознал`, `⏱ мозг думал`, `⏱ голос`.
- **Мгновенно** (без нейросети) выполняются: который час, какое число, громче/тише/без звука, пауза, следующий/предыдущий трек, заблокируй компьютер, открой дашборд.
- **Мозг думает долго** (больше 3 с) → в ⚙ Настройках выберите модель `gpt-4.1-mini`: она в 2–3 раза быстрее. Многошаговые задачи (почта, несколько действий подряд) всегда дольше: каждый шаг — отдельный запрос.
- Говорите «Джарвис, *команда*» одной фразой — так быстрее, чем «Джарвис» → сигнал → команда.

### Настройки и доступы
Всё настраивается в дашборде: кнопка **⚙ Настройки и доступы** (или http://localhost:5050/settings). Там же — инструкция, какие доступы дать Windows. После сохранения перезапустите Джарвиса.

### Как обновлять Джарвиса
Скачайте архив ветки, распакуйте его поверх папки с заменой файлов и запустите **`update_jarvis.bat`**. Ваши настройки, дела и память сохранятся.

### Если что-то не работает
| Проблема | Решение |
|---|---|
| `401 OAuth access token is invalid` | Claude Code разлогинился. В PowerShell: `claude` → `/login` → войти заново. Пока этого не сделать, Джарвис отвечает через OpenAI (если есть ключ) |
| `NoAudioReceived`, долгие ответы голосом | бесплатный голос Microsoft не отвечает. Запустите `update_jarvis.bat` (новая версия edge-tts). Если не помогло — в ⚙ Настройках «Какой голос первым» → `openai` |
| Анимация только на одном мониторе / в браузере | запустите `update_jarvis.bat`: он поставит pywebview, и Джарвис будет открывать настоящие окна на каждом мониторе |
| После обновления из архива что-то не запускается | запустите `update_jarvis.bat` — он доставит новые библиотеки |
| Иногда говорит женским голосом | основной голос (онлайн-сервис Microsoft) не ответил, и включился запасной голос Windows — на большинстве ПК он только женский (Irina). Джарвис теперь делает 3 попытки. Если женский голос не нужен совсем — в ⚙ Настройках «Запасной голос» → `false` (тогда при сбое ответ будет только текстом в окне) |
| `pip install` ругается на PyAudio | поставьте Python **3.12** (не 3.14) и запустите `install_windows.bat` заново |
| Джарвис не слышит | Параметры Windows → Конфиденциальность → Микрофон → разрешить приложениям; проверьте микрофон по умолчанию |
| Реагирует на телевизор или шум | говорите ближе к микрофону; можно сменить слово-активатор в `WAKE_WORDS` |
| «Ключ OpenAI не подходит» / «Лимит исчерпан» | проверьте `OPENAI_API_KEY` в `.env` и баланс на platform.openai.com |
| Почта: ошибка входа | нужен пароль приложения, а не обычный пароль; включите IMAP в настройках почты |
